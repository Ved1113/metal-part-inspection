# Week 1 - Image and Video Basics

## Overview

This week focuses on the fundamentals of image and video processing using Python, OpenCV, and NumPy.

The exercises cover reading and displaying images, understanding images as NumPy arrays, color spaces, basic image transformations, drawing operations, masking, and webcam video processing.

## Topics Covered

- Image reading and writing
- Displaying images using OpenCV
- Understanding image shape and pixels
- BGR and grayscale images
- Image resizing
- Cropping and ROI
- Image rotation
- Image flipping
- Drawing shapes
- Drawing text
- Bitwise operations and masking
- Webcam capture
- Video recording

## Files

| File | Description |

| `main.py` | Image shape, channels and pixel analysis |

| `rectangle.py` | Draws a rectangle |
