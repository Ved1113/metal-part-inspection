\# Week 7 — Segmentation, Measurement \& Anomaly Detection



\## Overview

This week focused on segmentation, defect measurement, severity analysis, and anomaly detection for metal-part inspection.



\## Work Done

\- Studied semantic and instance segmentation.

\- Worked with YOLOv8 segmentation concepts.

\- Studied U-Net for image segmentation.

\- Measured defect area and length using segmentation masks.

\- Understood defect severity based on defect size.

\- Studied anomaly detection for rare and unseen defects.

\- Covered Autoencoders, PaDiM, and PatchCore.



\## Objective

The objective was to move from simple defect detection toward detailed defect segmentation, measurement, severity assessment, and detection of unusual defects.
